# Tunnel Setup

## Tunnel
Name:
`diaco-accounting`

## Windows connector
Install the current 64-bit Windows version of cloudflared from Cloudflare.

Verify installation:
`cloudflared.exe --version`

The version observed during the original setup was 2026.9.1.

## Service installation
Use the tunnel-specific Windows service install command generated by the Cloudflare dashboard.

Do not copy the tunnel enrollment string into this repository.

## Verify the Windows service
Run an Administrator Command Prompt:

`sc query cloudflared`

Expected state:
`STATE : 4 RUNNING`

## Connector diagnostics
Useful command:
`cloudflared tunnel diag`

The local diagnostics endpoint used during troubleshooting:
`http://localhost:20241/diag/tunnel`

A successful connector showed:
`"isConnected": true`

## Published application
Public hostname:
`account.diacoelectronix.ir`

Service type:
`HTTP`

Service URL:
`http://127.0.0.1:5000`

Path:
leave empty.

Important: the working service URL does not have a trailing slash after 5000.

## Final test
Open from outside the LAN:
`https://account.diacoelectronix.ir`

Expected result: accounting application login page.
